# Hermes Skills

A collection of reusable [Hermes Agent](https://hermes-agent.nousresearch.com) skills for managing servers, APIs, and more.

## Skills

### [1panel-management](./1panel-management/)

Control your [1Panel](https://1panel.cn) Linux server management panel programmatically via its REST API.

**What you can do:**
- Query dashboard overview (system info, website/database/cron counts)
- List network interfaces and monitor system resources
- Search system settings and node info
- Bypass captcha via direct SQLite access (root required)

**Install:**
```bash
hermes skills install https://raw.githubusercontent.com/Satyachen/biubiu/main/skills/1panel-management/SKILL.md
```
